2. Exercice 1 : Exécution concourante (Père/Fils)

Analyse & Objectifs

Le but de cet exercice est d'illustrer la concourance de processus. À l'aide de l'appel système fork(), un processus père se sépare en deux. Le processus fils doit afficher tous les entiers successifs de $1$ à $N$, tandis que le processus père doit filtrer et n'afficher que les entiers pairs sur cette même plage. Afin d'éviter l'état de zombie pour le fils, le père doit suspendre son exécution grâce à wait() jusqu'à la fin de la tâche de son enfant.

Code Source (exercice1.c)

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/types.h>
#include <sys/wait.h>

int main(int argc, char *argv[]) {
    int n = 10;
    
    if (argc > 1) {
        n = atoi(argv[1]);
        if (n <= 0) {
            fprintf(stderr, "Erreur : N doit être strictement positif.\n");
            return 1;
        }
    }

    printf("[Début] PID principal: %d | N = %d\n", getpid(), n);

    pid_t pid = fork();

    if (pid < 0) {
        perror("Erreur fork");
        return 1;
    } 
    else if (pid == 0) {
        // --- Code du Fils ---
        printf("\n[Fils - PID: %d] Début de l'affichage de 1 à %d :\n", getpid(), n);
        for (int i = 1; i <= n; i++) {
            printf("  -> [Fils - PID: %d] Nombre : %d\n", getpid(), i);
            usleep(10000);
        }
        printf("[Fils - PID: %d] *** Fin du processus fils ***\n\n", getpid());
        exit(EXIT_SUCCESS);
    } 
    else {
        // --- Code du Père ---
        printf("\n[Père - PID: %d] Début de l'affichage des pairs de 1 à %d :\n", getpid(), n);
        for (int i = 1; i <= n; i++) {
            if (i % 2 == 0) {
                printf("  -> [Père - PID: %d] Nombre Pair : %d\n", getpid(), i);
                usleep(10000);
            }
        }
        
        // Attente de la fin du fils
        int status;
        wait(&status);
        
        printf("[Père - PID: %d] *** Mon fils est terminé, fin du père ***\n", getpid());
    }

    return 0;
}

3. Exercice 2 : Arborescence de 15 processus sous contraintes

Analyse & Contraintes du Problème

Nous devons créer un arbre comptant exactement 15 processus respectant les contraintes :

  • Le processus de départ (racine) $P_0$ fait partie des 15.
  • Chaque nœud a soit $0$, soit $2$, soit $3$ enfants (interdiction formelle d'avoir un enfant unique).
  • Tous les enfants directs du processus initial ($P_0$) doivent obligatoirement engendrer eux-mêmes des enfants.
  • Le code source C doit être minimaliste et contenir le nombre le plus réduit possible d'instructions fork().

Modélisation & Justification Théorique

Pour satisfaire ces règles complexes, nous concevons l'arbre par niveaux :

  • Niveau 0 (Racine) : Le processus initial $P_0$. Pour respecter la règle 3, nous lui donnons **3 fils** ($P_1$, $P_2$, $P_3$).
  • Niveau 1 : Le groupe des 3 fils de $P_0$. Pour qu'ils aient tous des descendants (Règle 3), nous donnons **2 fils** à chacun d'eux.
    • $P_1$ enfante $P_4$ et $P_5$.
    • $P_2$ enfante $P_6$ et $P_7$.
    • $P_3$ enfante $P_8$ et $P_9$.
    Nous comptons ici : $1$ (racine) + $3$ (niveau 1) + $6$ (niveau 2) = $10$ processus. Il en reste $5$ à placer.
  • Niveau 2 : Parmi ces 6 nœuds, nous devons faire naître exactement 5 enfants. Pour respecter la contrainte de degré (0, 2 ou 3 fils), nous donnons **2 fils** à $P_4$ ($P_{10}$, $P_{11}$) et **3 fils** à $P_5$ ($P_{12}$, $P_{13}$, $P_{14}$). Les autres processus ($P_6$ à $P_9$) n'ont pas de fils.
  • Niveau 3 : Les feuilles de l'arbre ($P_{10}$ à $P_{14}$) n'engendrent aucun fils.

Justification du compte total : $$N = N_{\text{Niv0}} + N_{\text{Niv1}} + N_{\text{Niv2}} + N_{\text{Niv3}}$$ $$N = 1 + 3 + 6 + 5 = 15 \text{ processus.}$$ Le degré de chaque nœud est toujours égal à 0 (feuilles), 2 ($P_1, P_2, P_3, P_4$) ou 3 ($P_0, P_5$), validant la contrainte.

Code Source (exercice2.c)

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/types.h>
#include <sys/wait.h>

void executer_processus(int id) {
    int nb_fils = 0;
    int ids_fils[3];

    // Configuration de l'arborescence
    if (id == 0) {
        nb_fils = 3;
        ids_fils[0] = 1; ids_fils[1] = 2; ids_fils[2] = 3;
    } else if (id == 1) {
        nb_fils = 2;
        ids_fils[0] = 4; ids_fils[1] = 5;
    } else if (id == 2) {
        nb_fils = 2;
        ids_fils[0] = 6; ids_fils[1] = 7;
    } else if (id == 3) {
        nb_fils = 2;
        ids_fils[0] = 8; ids_fils[1] = 9;
    } else if (id == 4) {
        nb_fils = 2;
        ids_fils[0] = 10; ids_fils[1] = 11;
    } else if (id == 5) {
        nb_fils = 3;
        ids_fils[0] = 12; ids_fils[1] = 13; ids_fils[2] = 14;
    }

    printf("Processus ID-Logique: %2d | mon PID: %5d | mon Père: %5d | va créer %d fils\n",
           id, getpid(), getppid(), nb_fils);

    // Une seule ligne fork() écrite textuellement
    for (int i = 0; i < nb_fils; i++) {
        pid_t pid = fork();
        
        if (pid < 0) {
            perror("Erreur fork");
            exit(EXIT_FAILURE);
        } 
        else if (pid == 0) {
            executer_processus(ids_fils[i]);
            exit(EXIT_SUCCESS); 
        }
    }

    for (int i = 0; i < nb_fils; i++) {
        wait(NULL);
    }

    printf("Processus ID-Logique: %2d | PID: %5d se termine proprement.\n", id, getpid());
}

int main() {
    printf("=======================================================================\n");
    printf("  Génération de l'arborescence de 15 processus (Contraintes respectées) \n");
    printf("=======================================================================\n");

    executer_processus(0);

    printf("\n[Succès] Processus racine a attendu tous ses descendants. Fin.\n");
    return 0;
}

4. Exercice 3 : Manipulation bas niveau et lseek

Analyse & Algorithme d'insertion

Nous devons écrire le texte initial "le noyau réalise une préemption du processeur lorsqu'il dépasse son temps." dans un fichier testFile.txt, puis y insérer le texte "quantum de " juste avant la portion "son temps.".

Problème : Si nous modifions directement le pointeur physique avec lseek à l'adresse de destination et écrivons de nouvelles données, l'ancienne portion située à cet endroit sera détruite (écrasée) octet par octet. Il est donc capital de :

  • Écrire la première phrase.
  • Lire le contenu du fichier, localiser la position absolue de la chaîne "son temps".
  • Sauvegarder dans un buffer temporaire la suite restante ("son temps.").
  • Utiliser lseek() pour déplacer le curseur d'écriture à cette position absolue.
  • Écrire le morceau intercalaire "quantum de ".
  • Réécrire le suffixe de fin que l'on avait pris le soin de sauvegarder juste avant.

Code Source (exercice3.c)

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <fcntl.h>
#include <unistd.h>

int main() {
    const char *filename = "testFile.txt";
    const char *initial_text = "le noyau réalise une préemption du processeur lorsqu'il dépasse son temps.";
    const char *insert_text = "quantum de ";
    const char *target = "son temps";

    printf("[1] Création et ouverture de %s...\n", filename);
    int fd = open(filename, O_RDWR | O_CREAT | O_TRUNC, 0644);
    if (fd < 0) {
        perror("Erreur open");
        return 1;
    }

    // Écriture du texte original
    write(fd, initial_text, strlen(initial_text));

    // Retour au début pour chercher l'emplacement cible
    lseek(fd, 0, SEEK_SET);
    char buffer[256];
    memset(buffer, 0, sizeof(buffer));
    read(fd, buffer, sizeof(buffer) - 1);

    char *pos = strstr(buffer, target);
    if (!pos) {
        fprintf(stderr, "Erreur : sous-chaîne cible introuvable.\n");
        close(fd);
        return 1;
    }

    off_t offset = pos - buffer;
    printf("[2] Position cible identifiée à l'offset : %ld\n", (long)offset);

    // Sauvegarde du reste de la phrase
    char saved_suffix[128];
    strcpy(saved_suffix, pos);

    // Positionnement à l'offset de destination et insertion
    lseek(fd, offset, SEEK_SET);
    write(fd, insert_text, strlen(insert_text));
    write(fd, saved_suffix, strlen(saved_suffix));

    // Lecture pour vérification
    lseek(fd, 0, SEEK_SET);
    memset(buffer, 0, sizeof(buffer));
    read(fd, buffer, sizeof(buffer) - 1);

    printf("\n[Résultat] Contenu final lu du fichier :\n\"%s\"\n", buffer);

    close(fd);
    return 0;
}

5. Exercice 4 : Exploration de dossiers (Equivalent ls -ai)

Analyse & Explications

La commande ls -ai sert à lister tous les éléments du dossier de travail :

  • -a : extrait l'ensemble des fichiers, même cachés (tous ceux qui démarrent par un point ., comme . et ..).
  • -i : affiche pour chaque entrée le numéro d'identifiant unique physique nommé inode.

Pour reproduire cette commande de façon conforme en C, nous manipulons les primitives systèmes d'exploration de dossiers : opendir() pour cibler le dossier courant ".", puis une boucle avec readdir(). Cette dernière nous renvoie à chaque tour une variable contenant le nom (d_name) et le numéro d'inode (d_ino).

Code Source (exercice4.c)

#include <stdio.h>
#include <stdlib.h>
#include <dirent.h>
#include <sys/types.h>

int main() {
    DIR *dir = opendir(".");
    if (dir == NULL) {
        perror("Erreur opendir");
        return 1;
    }

    printf("=======================================================================\n");
    printf("     Affichage du répertoire courant - Équivalent de 'ls -ai'          \n");
    printf("=======================================================================\n");

    struct dirent *entry;
    int count = 0;

    while ((entry = readdir(dir)) != NULL) {
        printf("%10lu %s\n", (unsigned long)entry->d_ino, entry->d_name);
        count++;
    }

    closedir(dir);
    printf("=======================================================================\n");
    printf("[Succès] Fin. Nombre d'éléments trouvés : %d\n", count);
    return 0;
}

6. Exercice 5 : Synchronisation et exécution de binaires (ls et ps)

Analyse Technique

Cet exercice combine l'exécution concurrente de commandes systèmes réelles et la capture d'événements par le processus parent. Le parent engendre deux processus enfants. Chaque fils recouvre son espace mémoire via la primitive execlp() pour lancer respectivement :

  • Le binaire ls avec l'argument -l pour le premier fils.
  • Le binaire ps avec l'argument -l pour le second fils.

Le père se bloque sur l'appel système wait(). Le premier processus fils qui finit d'exécuter sa commande réveille le père en lui transmettant son PID. Le père compare alors ce PID avec ceux mémorisés pour déterminer le vainqueur. Il exécute ensuite un second appel à wait() pour clore proprement l'exécution globale.

Code Source (exercice5.c)

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/types.h>
#include <sys/wait.h>

int main() {
    pid_t pid_ls, pid_ps;

    printf("[Père - PID: %d] Initialisation des deux tâches...\n\n", getpid());

    // 1. Création fils LS
    pid_ls = fork();
    if (pid_ls < 0) {
        perror("Erreur fork ls");
        return 1;
    } 
    else if (pid_ls == 0) {
        printf("[Fils LS - PID: %d] Exécution de 'ls -l'...\n", getpid());
        execlp("ls", "ls", "-l", NULL);
        perror("Erreur exec ls");
        exit(EXIT_FAILURE);
    }

    // 2. Création fils PS
    pid_ps = fork();
    if (pid_ps < 0) {
        perror("Erreur fork ps");
        return 1;
    } 
    else if (pid_ps == 0) {
        printf("[Fils PS - PID: %d] Exécution de 'ps -l'...\n", getpid());
        execlp("ps", "ps", "-l", NULL);
        perror("Erreur exec ps");
        exit(EXIT_FAILURE);
    }

    // 3. Attente et détection du premier fils terminé
    int status;
    pid_t premier_termine = wait(&status);

    printf("\n=======================================================================\n");
    if (premier_termine == pid_ls) {
        printf("[Résultat] Le PREMIER à finir est : Fils 1 ('ls -l') [PID: %d]\n", premier_termine);
    } 
    else if (premier_termine == pid_ps) {
        printf("[Résultat] Le PREMIER à finir est : Fils 2 ('ps -l') [PID: %d]\n", premier_termine);
    } 
    else {
        printf("[Résultat] Processus inconnu [PID: %d]\n", premier_termine);
    }
    printf("=======================================================================\n");

    // Attente du second processus
    wait(&status);
    printf("[Père] Le second fils s'est terminé. Fin propre.\n");

    return 0;
}

Analyse du résultat temporel

Le travail demandé à la commande ls requiert une simple lecture locale sur le système de fichiers, ce qui est extrêmement optimisé et instantané. À l'inverse, ps interroge le cœur de l'OS en mémoire virtuelle (/proc sous Linux) pour récupérer la liste des processus systèmes en cours, tâche intrinsèquement plus coûteuse. Par conséquent, la commande ls -l se termine presque systématiquement en premier.

7. Exercice 6 : Traduction d'UID en clair (getpwuid & getgrgid)

Analyse & Structures Système

Les comptes d'utilisateurs Unix sont associés à des identifiants chiffrés (les UID). Pour les convertir en texte humain lisible :

  • La fonction getpwuid(uid) va chercher dans la table des comptes système (le fichier /etc/passwd) et renvoie un pointeur vers une structure passwd (dont le champ pw_name contient le nom).
  • Le champ pw_gid de cette même structure fournit l'identifiant numérique de son groupe de travail principal. En passant ce dernier à getgrgid(gid), on obtient une structure de type group contenant le nom du groupe (gr_name).
  • Si l'UID n'existe pas dans le système, la fonction renvoie un pointeur nul (NULL), nous permettant de renvoyer le message d'erreur prescrit par l'énoncé.

Code Source (exercice6.c)

#include <stdio.h>
#include <stdlib.h>
#include <sys/types.h>
#include <pwd.h>
#include <grp.h>

int main(int argc, char *argv[]) {
    if (argc < 2) {
        printf("[Usage] %s \n", argv[0]);
        return 1;
    }

    int uid_int = atoi(argv[1]);
    uid_t uid = (uid_t)uid_int;

    // Récupération de l'utilisateur
    struct passwd *pw = getpwuid(uid);

    if (pw == NULL) {
        // Message d'erreur obligatoire
        printf("il n'y a pas d'utilisateur associé à cet uid.\n");
        return 0;
    }

    printf("=======================================================================\n");
    printf("     Informations d'identité pour l'UID %d (Trouvé !)                  \n");
    printf("=======================================================================\n");
    printf("- Nom d'utilisateur (Login)    : %s\n", pw->pw_name);
    printf("- Répertoire personnel (Home)  : %s\n", pw->pw_dir);
    printf("- Shell de connexion           : %s\n", pw->pw_shell);

    // Récupération du nom du groupe en clair
    struct group *gr = getgrgid(pw->pw_gid);
    if (gr != NULL) {
        printf("- Groupe principal             : %s (GID: %d)\n", gr->gr_name, pw->pw_gid);
    } else {
        printf("- Groupe principal             : inconnu (GID: %d)\n", pw->pw_gid);
    }
    printf("=======================================================================\n");

    return 0;
}
